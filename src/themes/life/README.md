# VNU Life theme

`lifeTheme.ts` extends Astryx Matcha0.7.16 (Meta Platforms, MIT; see the license at `.agents/skills/astryx/LICENSE`). It keeps the semantic palette and uses local system fonts for body/heading/code, without Google Fonts or font-service requests. Georgia headings fall back to Times New Roman/serif; body uses system-ui/Segoe UI/Arial.

Run `npm run theme:build` after changing the source. The CLI generates `life.js`, `life.css` and declarations; do not hand-edit them. `src/astryx-themes.ts` is generated by the theme CLI and registers this built theme for SSR. Application interaction/Leaflet/3D layout styles remain in their existing files and reference semantic tokens.
